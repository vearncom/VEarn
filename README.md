# Welcome to VEarn
## Gain Knowledge. Earn Smart.

Welcome to VEarn. This is a premium website where you can buy digital e-books and listen to audio courses about how to earn smart. We sell high-quality guides to help you understand the future of money, learn how to use AI tools, achieve your financial goals, and discover new ways to make money in the modern world. Download your first book today, explore our collection, and start earning smarter!

## 🌟 Key Features

1. **SPA Tab Navigation**: Dynamic, fluid transitions switching between **Home**, **E-Books**, and **Audio Courses** views inside a single, zero-dependency `index.html` file.
2. **Visual Masterpiece**: Rich luxury champagne gold gradients, fine grid tech matrices, interactive background glowing orbs, and glassmorphism.
3. **Interactive 3D Tilt Card**: A premium floating circular emblem widget on the Home portal that tracks the user's cursor tilt coordinates in real-time.
4. **Built-in Vinyl Audio Player**:
   - Dynamic spinning record graphics that activate on playback.
   - Pulsing custom equalizers synchronizing sound frequencies.
   - Seamless scrubbable timeline seek bar mapping.
   - Integrated Web Audio API browser synthesizer generating triangle sound waves on demand.
5. **Secure Credit Card Checkout Modal**:
   - Synchronized visual credit card rendering inputs (card number, expiration dates,holder details) dynamically mapped.
   - Secure authorization spinner transitions.
   - Interactive falling canvas confetti celebration on success.

## 🚀 How to Run Locally

Since this project has been fully consolidated into a zero-dependency SPA, there is no setup required:
1. Double-click the `index.html` file in your file explorer to open it instantly in any modern web browser.
2. Alternatively, run a simple local server if you'd like to host it:
   ```bash
   npx serve .
   ```
